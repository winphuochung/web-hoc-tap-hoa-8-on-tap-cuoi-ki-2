# Web/app học tập — Hóa học 8, Ôn tập kiểm tra cuối kì II

**Ôn tập kiểm tra cuối kì II (Bài 8–12)** — Tuần 32–33 · Tiết 45–46
Môn Khoa học tự nhiên 8 (phân môn Hóa học) — Chương trình GDPT 2018, sách Kết nối tri thức với cuộc sống.

Giáo viên: Lê Văn Thắng — Trường TH và THCS Phước Hưng, xã Nhơn Hội, tỉnh An Giang.

## Nội dung

Web/app học tập 6 phần: Khởi động, Hệ thống kiến thức, Mô phỏng, Sơ đồ tư duy, Luyện tập (10 câu trắc nghiệm tự chấm), Vận dụng.

Phạm vi ôn tập (theo PDF gốc): Bài 8. Acid; Bài 9. Base. Thang pH; Bài 10. Oxide; Bài 11. Muối; Bài 12. Phân bón hoá học.

Mô phỏng gồm:
1. Acid — HCl với giấy quỳ tím và kim loại kẽm (SGK trang 36).
2. Base và phản ứng trung hoà — NaOH với quỳ tím, phenolphthalein, rồi nhỏ HCl vào (SGK trang 40, Hình 9.1).
3. Tính chất của muối — 4 ống nghiệm (SGK trang 50, Hình 11.1).

Khóa đáp án trắc nghiệm: **1A 2B 3A 4D 5A 6C 7A 8C 9B 10C** (giữ nguyên key gốc trong PDF ôn tập).

## Trạng thái gửi điểm: CHỜ /exec

Link Web App (Apps Script) của bài này **chưa có** — file `index.html` hiện **không** chứa code gửi điểm về Google Sheets (0 lần `/exec`, 0 lần `script.google.com`). Điểm trắc nghiệm chỉ lưu trên máy học sinh (điểm cao nhất lưu localStorage). Khi có link Web App, thêm fetch POST vào vị trí đã đánh dấu trong code rồi đẩy lại lên GitHub/Vercel.

## Cách dùng

- Mở file `index.html` bằng trình duyệt bất kì (không cần máy chủ).
- Học sinh đăng nhập bằng Họ tên + Lớp, học 6 phần, làm 10 câu trắc nghiệm rồi nộp bài.
